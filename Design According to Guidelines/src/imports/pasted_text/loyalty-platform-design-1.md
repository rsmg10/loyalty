Design a modern, scalable multi-tenant loyalty platform with three main experiences:

1) Customer Mobile App
2) Business Portal (for business owners and staff)
3) Admin Portal (for system administrators)

The platform allows multiple businesses (cafes, restaurants, etc.) to run their own loyalty programs, while customers can use one app to interact with many businesses.

==================================================
OVERALL DESIGN GOALS
==================================================

- Clean, modern SaaS design
- Highly usable and intuitive
- Mobile-first for customer app
- Dashboard-focused for portals
- Scalable design system (components, spacing, typography)
- Clear hierarchy and navigation
- Professional but slightly engaging for customer experience

==================================================
CUSTOMER MOBILE APP
==================================================

Design a polished mobile app with a simple and engaging experience.

Key Screens:

1. Onboarding & Authentication
- Welcome screens
- Login / signup (phone/email)

2. Home Screen
- Active loyalty cards (from different businesses)
- Nearby or recommended businesses
- Personalized offers
- Clear, card-based layout

3. Explore / Search
- Search businesses
- Filter by category (coffee, restaurant, dessert, etc.)
- Clean list/grid layout

4. Business Profile
- Business branding (logo, colors)
- Description
- Loyalty programs available
- Rewards and prizes
- Call to action to join

5. Loyalty Card / Progress
- Visual progress (steps, stamps, or progress bar)
- Milestones clearly shown
- Highlight unlocked rewards
- Show how many steps remaining

6. Offers & Rewards
- List of available offers
- Reward details screen
- Clear “redeem” state

7. Redemption Flow
- Show QR/code
- Confirmation screen
- Success state

8. Profile
- User info
- Joined businesses
- History of rewards/redemptions

UX Style:
- Card-based UI
- Soft colors + clean spacing
- Slightly gamified (progress, badges)
- Very easy to understand at a glance

==================================================
BUSINESS PORTAL (OWNER + STAFF)
==================================================

Design a web dashboard for businesses.

Layout:
- Sidebar navigation
- Top bar with actions and user menu
- Responsive but desktop-first

Key Sections:

1. Dashboard
- KPIs (customers, redemptions, activity)
- Charts and summaries
- Recent activity

2. Loyalty Programs
- List of programs
- Create/edit program
- Define steps and rewards
- Simple form-based UI

3. Offers & Rewards
- List and manage offers
- Enable/disable offers
- Simple scheduling UI

4. Customers
- Table of customers
- Basic insights (visits, activity)
- Customer detail view

5. User Management (IMPORTANT)
- List users in the business
- Add/invite user
- Edit user
- Assign roles (Owner, Manager, Staff)
- Activate/deactivate users
- Clear role badges and status indicators

6. Staff Operations
- Fast interface for validating rewards
- Search customer
- Scan QR or enter code
- Confirm redemption
- Minimal distractions, optimized for speed

7. Settings
- Business profile
- Branding
- General configuration

UX Style:
- Clean dashboard UI
- Tables + cards + charts
- Clear navigation
- Efficient workflows

==================================================
ADMIN PORTAL (SYSTEM LEVEL)
==================================================

Design an enterprise-style admin dashboard.

Key Sections:

1. Platform Dashboard
- Total businesses
- Total users
- Activity metrics
- Platform health overview

2. Tenant Management
- List of businesses
- View tenant details
- Status (active, suspended)
- Basic actions (approve, disable)

3. User Management (IMPORTANT)
- View all users across platform
- Filter by:
  - Customers
  - Business users
  - Admin users
- Search and sort
- View user details
- Activate/deactivate users
- Assign roles for admin users

4. Support / Troubleshooting
- Lookup users or businesses
- View activity summary
- Simple audit-style view

5. Global Settings
- Platform configurations
- Categories/tags if needed

UX Style:
- Dense but structured
- Table-heavy
- Clear hierarchy
- Enterprise SaaS look

==================================================
DESIGN SYSTEM
==================================================

Create a consistent design system including:
- Color palette (primary, secondary, neutral)
- Typography scale
- Buttons (primary, secondary, disabled)
- Inputs and forms
- Cards
- Tables
- Badges (for roles/status)
- Modals and dialogs
- Navigation components (sidebar, tabs)

==================================================
IMPORTANT NOTES
==================================================

- Clearly differentiate between:
  - Customer experience (mobile, engaging)
  - Business tools (efficient, clean)
  - Admin tools (structured, data-heavy)

- Show role-based UI where relevant:
  - Owner vs Staff differences
  - Admin-level control

- Focus on usability over decoration

- Avoid clutter, keep layouts clean and scalable

==================================================
OUTPUT
==================================================

Produce:
- Full set of screens for all three experiences
- Reusable components
- Consistent layout system
- Clear user flows:
  - Customer joins a loyalty program
  - Customer redeems a reward
  - Business creates a program
  - Staff validates a reward
  - Admin manages users and tenants
